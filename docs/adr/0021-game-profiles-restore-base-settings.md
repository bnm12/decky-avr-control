# A receiver-bound global profile restores settings when games exit

A per-game profile overrides only the settings it remembers. A hidden global profile stores the everyday volume and listening mode for each receiver. For each setting, the active profile is the running game's profile when that game remembers it; otherwise it is the receiver's global profile. Changes through the panel, receiver, or application update only that active profile. Late-night volume is never written to either profile.

On game launch, the plugin applies the game's remembered settings. On handoff, the previous game's restore completes before the next profile is applied. On exit—and when a remember toggle is turned off during play—it applies the global values for the settings that were overridden, clamping volume to the cap then in effect and applying mode only when supported. A game's session records which settings were actually overridden and the receiver binding, so a receiver switch never restores another receiver's values. That session and the per-receiver global profiles persist across plugin restarts.

Profile transitions are serialized. Each receiver observation captures the transition generation when its I/O starts; if that generation changes before a profile write, the write is discarded. Only fresh receiver status, fresh push fields, and setter confirmations may update profiles; cached or derived snapshots never do. No timer discards a fresh observation that starts after a transition completes. Global seeding waits for Steam game-state synchronization, except that a fresh pre-apply launch status may seed missing values for settings the launched game overrides. Late-night volume is excluded from profiles; when a game volume override ends, the late-night restore volume follows the global value for the same receiver.

On handoff, restore the previous game's settings that the next game's profile does not remember before applying the next profile. A failed handoff restore remains persisted independently of the new game's session, but is canceled for any setting the next game opts into. Enabling a setting for the current game also cancels queued restores for that setting on the same receiver. Restores retry only while power is confirmed on when the driver supports power reporting; drivers without that capability may restore after a successful status read. Retries are spaced, bounded, and expire after ten minutes; each setting clears only after matching confirmation. Expired or exhausted restores are logged and dropped rather than applied later. An unchanged Steam game-state update does not invalidate delayed mode re-apply; its validity is tracked separately from observation fencing.

Global profiles are keyed by the receiver binding (ADR-0014) and store the driver key because raw volumes and listening-mode codes are driver-specific (ADR-0012). The global profile is internal: it is not shown with game profiles and cannot be forgotten.
