# A receiver-bound global profile restores settings when games exit

A per-game profile overrides only the settings it remembers. A hidden global profile stores the everyday volume and listening mode for each receiver. For each setting, the active profile is the running game's profile when that game remembers it; otherwise it is the receiver's global profile. Changes through the panel, receiver, or application update only that active profile. Late-night volume is never written to either profile.

On game launch, the plugin applies the game's remembered settings. On handoff, the previous game's restore completes before the next profile is applied. On exit—and when a remember toggle is turned off during play—it applies the global values for the settings that were overridden, clamping volume to the cap then in effect and applying mode only when supported. A game's session records which settings were actually overridden and the receiver binding, so a receiver switch never restores another receiver's values. That session and the per-receiver global profiles persist across plugin restarts.

Profile transitions are serialized. Each receiver observation captures the transition generation when its I/O starts; if that generation changes before a profile write, the write is discarded. Saves are also suppressed during a transition and briefly after a profile apply or restore, independent of whether a game session remains. A global setting is seeded only from a trusted everyday observation, never while a running game overrides it or a restore is pending. Late-night volume is excluded from profiles; when a game volume override ends, the late-night restore volume follows the global value for the same receiver.

Global profiles are keyed by the receiver binding (ADR-0014) and store the driver key because raw volumes and listening-mode codes are driver-specific (ADR-0012). Pending global restores persist an expiry ten minutes after exit and a bounded retry count; each setting clears only after matching confirmation. Expired or exhausted restores are logged and dropped rather than applied later. The global profile is internal: it is not shown with game profiles and cannot be forgotten.
